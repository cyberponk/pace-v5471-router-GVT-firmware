Dynamic DNS

Keeps names pointing to this router's public IP address, with one or more services. The new providers update over HTTPS with certificate checks (10 s timeout); the public address is read from a check-IP service, so it also works behind another router. All services are checked at every WAN connection and every 5 minutes.

Service
Enabled:Updates this service. Off keeps it in the list without updating.
Provider:Service where the name is registered.
Server:DynDNS 2 update server (dynv6.com for dns.army, dynv6.net and the other dynv6 domains).
Update URL:Full update URL from the provider, for example the cPanel dynamic DNS URL. Called with HTTPS (http:// is changed to https://); the server takes the address the call comes from.
Username:Your account at the provider.
Password:Password of that account. Leave empty to keep the stored one.
Hostname:Full name to update, for example myhome.dns.army or myhome.nsupdate.info.
