Backup / Restore

Saves all the settings (Wi-Fi, passwords, network, services) to a file or on the router, and puts them back. Restoring replaces the current settings and restarts the device. The files hold the passwords (Wi-Fi, administrator, shell) in a form that can be decoded: keep them private.
